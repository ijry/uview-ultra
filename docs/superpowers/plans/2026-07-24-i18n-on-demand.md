# uview-ultra i18n 按需加载 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 uview-ultra 内置 i18n 改为默认仅内置 `zh-Hans`，其他语言通过 `registerLocale` 按需注册；JS 与 UTS 双端完整对齐，降低主包体积（#908）。

**Architecture:** `libs/i18n/index.js` / `index.uts` 只静态依赖 `zh-Hans` 并提供注册 API；可选语言经 `locale-packs.js` / `locale-packs.uts` 从包入口命名导出，与 `t` 的依赖图解耦。保留 ultra 的 `up_common_*` key 与 `t()` 内 `.`→`_` 变换。

**Tech Stack:** uni-app / uni-app-x、JS + UTS 语言模块、Node 静态与行为断言脚本、Markdown 文档仓。

## Global Constraints

- 默认仅内置 `zh-Hans`；`index.js` / `index.uts` 不得静态 import 其他语言。
- 禁止动态 `import()` 加载语言包。
- 保留 `up_common_*` key 与 `t()` 的 `.`→`_` 变换。
- 业务从包入口引入语言模块，无需深层路径。
- 重大变更写入插件 changelog 与 `uview-plus-doc4` 重大更新页。
- Git commit 中文 head + body，conventional 前缀。
- 设计依据：`docs/superpowers/specs/2026-07-24-i18n-on-demand-design.md`
- 发布版本：`4.5.9`
