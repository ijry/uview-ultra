# 2026-10-31

## up-audio 音频播放器（对齐 uview-plus 3.8.138，发布 4.5.77）

### 为什么是它
用户要求「找一个优化点，优化，然后发布新版」。扫描后发现 ultra 的
`up-parse` 还在用已废弃的原生 `<audio>` 标签渲染音频节点，而
`#ifndef MP-TOUTIAO || ((H5 || APP-PLUS) && VUE3)` 这个编译条件把该分支
在 uni-app Vue3（H5 / App-Vue）下直接排除——富文本里的音频**静默不渲染**。
上游 3.8.138 已用 `u-audio`（基于 uni.createInnerAudioContext）替换，
ultra 侧缺失。这是本次的优化点。

### 移植要点
- 组件 `components/up-audio/`：audio.js/.uts（默认值）、props.js、
  up-audio.vue（script setup）、up-audio.uvue（script setup lang="uts"）。
  多实例互斥的模块级实例池：.uvue 里**蒸汽模式不允许普通 `<script>` 块**
  （编译报「蒸汽模式仅支持使用<script setup>」），抽到独立模块
  audio-pool.js / audio-pool.uts（`Array<InnerAudioContext>`）。
- uvue 侧 props 默认值用 `defProps.getString/getBoolean('audio.xxx')`
  点路径（同 up-rate.uvue 模式）；src 是 `[String, Array]` 联合类型，
  取值用 `typeof == 'string'` 判断 + 同行 `as` 断言（P0 教训：断言不得换行）。
- slider 事件类型 `UniSliderChangeEvent`；error 回调
  `ICreateInnerAudioContextFail`（errMsg 必填 string）。
- `libs/config/props.js` 登记 Audio（import + spread，按字母序插入 Alert 后）。
- types：`types/comps/audio.d.ts` + comps.d.ts 登记 + **types/index.d.ts
  barrel 必须重新生成**（verify-types-barrel-exports 会比对，--print 输出
  替换 barrel 块，注意结束标记别重复）。
- up-parse/node/node.vue：`<audio>` 分支整体替换为 `<up-audio>`
  （`#ifndef APP-PLUS-NVUE`），import UpAudio，加 onAudioPlay/onAudioError
  转发（root?.$emit）。up-parse.uvue 走 rich-text 不渲染音频，未动。
- 示例页 pages/componentsD/audio/audio.uvue（单源 + 404 多源回退 +
  事件日志），pages.json 登记。
