### 新踩的坑：Git Bash 的 PATH 是 POSIX 形式，Node 的 spawnSync 解析不到 tar.exe

`spawnSync('tar', ['-xzf', …])` **静默失败**（status 非 0、输出为空、error 为空），
因为 Git Bash 传给子进程的 PATH 里是 `/usr/bin`，Windows 原生解析不了。
→ 改用 `npm pack` 打 tarball，再 `npm install <tarball> --prefix <tmp>` 让 npm 自己解包。
`npm.cmd` 反而能解析（它本来就在 Windows PATH 上）。
