## 注意点

- **uview-ultra 没有 npm 包**（`registry.npmjs.org/uview-ultra` 返回 404），
  所以 4.x 只发插件市场，不像 3.x 还要 `npm publish`。
- 插件市场发布**不打 tag**（仓库 tag 总数为 0）。
- `cachePath/notes.md` 上一版内容会残留，必须整体覆盖；
  它的首行要是 `fix:` / `feat:`，脚本不做格式校验，写坏了会直接进用户看到的更新日志。
- 发布脚本会自动改 `uni_modules/uview-ultra/package.json` 的 version 和 `changelog.md`，
  这两个文件要跟着一起提交。
- doc4 的 changelog 是纯 LF，用 Node 字符串插入即可；
  但 uview-plus4 是混合行尾，改那边要用「保留原始字节的字符串替换」。
